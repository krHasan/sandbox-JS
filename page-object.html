JavaScript objects are fundamental to the language, and understanding their methods, properties, and features is crucial for writing clean, efficient, and maintainable code. Below is a comprehensive guide to JavaScript objects, including examples of all methods, properties, and features.

Object Performance Considerations

  • Prefer Object.create(null) for pure dictionary objects to avoid prototype pollution.
  • Use Map for key-value pairs when keys are dynamic and frequent lookups are needed.
  • Use Object.freeze() on constant objects to prevent unintended mutations.

1. Creating a JavaScript Object

Object Literals (Most Common)


    const person = {
        firstName: "John",
        lastName: "Doe",
        age: 30,
        isEmployed: true,
        address: {
            city: "New York",
            country: "USA"
        },
        hobbies: ["reading", "traveling", "sports"],
        greet: function () {
            return `Hello, my name is ${this.firstName} ${this.lastName}.`;
        }
    };

Using Object.create()


    const personProto = {
        greet: function () {
            return `Hello, my name is ${this.firstName} ${this.lastName}.`;
        }
    };
    
    const person = Object.create(personProto);
    person.firstName = "John";
    person.lastName = "Doe";

Using Constructor Function


    function Person(firstName, lastName, age) {
        this.firstName = firstName;
        this.lastName = lastName;
        this.age = age;
        this.greet = function () {
            return `Hello, I'm ${this.firstName}.`;
        };
    }
    
    const person = new Person("John", "Doe", 30);

Using ES6 Class


    class Person {
        constructor(firstName, lastName, age) {
            this.firstName = firstName;
            this.lastName = lastName;
            this.age = age;
        }
    
        greet() {
            return `Hello, I'm ${this.firstName}.`;
        }
    }
    
    const person = new Person("John", "Doe", 30);

2. Object Properties and Methods

Accessing Properties

Dot Notation


    console.log(person.name); // "John"

Bracket Notation


    console.log(person["name"]); // "John"

Dynamic Property Access


    const key = "name";
    console.log(person[key]); // "John"

3. Adding/Updating Properties

Add a New Property


    person.job = "Developer";
    console.log(person.job); // "Developer"

Update an Existing Property


    person.age = 31;
    person["isEmployed"] = false;
    
    console.log(person.age); // 31

Deleting Properties


    delete person.age;
    console.log(person.age); // undefined

Checking if a Property Exists


    console.log("firstName" in person); // true
    console.log(person.hasOwnProperty("age")); // false (if deleted)

4. Object Methods

Object.keys(obj) – Get All Keys

Returns an array of an object's keys.


    console.log(Object.keys(person)); // ["firstName", "lastName", "isEmployed", "address", "hobbies", "greet"]

Object.values(obj) – Get All Values

Returns an array of an object's values.


    console.log(Object.values(person)); // ["John", "Doe", false, { city: "New York", country: "USA" }, ["reading", "traveling", "sports"], function]

Object.entries(obj) – Get Key-Value Pairs

Returns an array of key-value pairs.


    const entries = Object.entries(person);
    console.log(entries); // [["firstName", "John"], ["lastName", "Doe"], ["isEmployed", false], ...]

Object.assign(target, ...sources) – Copy Properties

Copies properties from one or more source objects to a target object.


    const newPerson = Object.assign({}, person, { job: "Developer" });
    console.log(newPerson); // { name: "John", age: 30, greet: [Function: greet], job: "Developer" }

Object.freeze(obj) – Prevent Modifications

Prevents modifications to an object.


    Object.freeze(person);
    person.age = 40; // Fails silently in non-strict mode
    console.log(person.age); // 30

Object.seal(obj) – Prevent Adding/Removing Properties

Prevents adding or deleting properties but allows modifying existing ones.


    Object.seal(person);
    person.age = 40; // Works
    person.job = "Developer"; // Fails
    console.log(person); // { name: "John", age: 40, greet: [Function: greet] }

Object.hasOwnProperty(prop) – Check Property Ownership

Checks if an object has a specific property.


    console.log(person.hasOwnProperty("name")); // true
    console.log(person.hasOwnProperty("job")); // false

Object.getOwnPropertyNames(obj) – Get All Property Names


    console.log(Object.getOwnPropertyNames(person));

Object.getPrototypeOf(obj) – Get Prototype


    console.log(Object.getPrototypeOf(person));

Object.defineProperty()

Defines a new property or modifies an existing one.


    Object.defineProperty(person, "job", {
        value: "Developer",
        writable: true,
        enumerable: true,
        configurable: true
      });
      console.log(person.job); // "Developer"

5. Looping Over an Object

Using for...in

Iterates over enumerable properties.


    for (const key in person) {
        console.log(`${key}: ${person[key]}`);
    }

Using Object.keys() + forEach


    Object.keys(person).forEach(key => {
        console.log(`${key}: ${person[key]}`);
    });

Using Object.entries() + forEach


    Object.entries(person).forEach(([key, value]) => {
        console.log(`${key}: ${value}`);
    });

6. Prototypes and Inheritance

Prototype Property


    function Person(name) {
        this.name = name;
    }

    Person.prototype.greet = function() {
        console.log(`Hello, my name is ${this.name}`);
    };

    const person = new Person("John");
    person.greet(); // "Hello, my name is John"

Inheritance with Object.create()


    const parent = {
        greet() {
            console.log(`Hello, my name is ${this.name}`);
        }
    };

    const child = Object.create(parent);
    child.name = "John";
    child.greet(); // "Hello, my name is John"

7. Getters and Setters

Getter


    const person = {
        firstName: "John",
        lastName: "Doe",
        get fullName() {
            return `${this.firstName} ${this.lastName}`;
        }
    };

    console.log(person.fullName); // "John Doe"

Setter


    const person = {
        firstName: "John",
        lastName: "Doe",
        set fullName(name) {
            [this.firstName, this.lastName] = name.split(" ");
        }
    };

    person.fullName = "Jane Smith";
    console.log(person.firstName); // "Jane"
    console.log(person.lastName); // "Smith"

8. Object Destructuring

Extract properties into variables.


    const { firstName, lastName, address: { city } } = person;
    console.log(firstName, city); // "John", "New York"

9. Object Spread & Rest Operators

Copy or merge objects.


    const person = { name: "John", age: 30 };
    const details = { job: "Developer", country: "USA" };
    
    const merged = { ...person, ...details };
    console.log(merged); // { name: "John", age: 30, job: "Developer", country: "USA" }

Cloning an Object


    const newPerson = { ...person };

Extracting Remaining Properties


    const { firstName, lastName, ...rest } = person;
    console.log(rest); // Everything except firstName and lastName

10. `this` in Objects

Refers to the object itself.


    const person = {
        name: "John",
        greet() {
            console.log(`Hello, my name is ${this.name}`);
        }
    };

    person.greet(); // "Hello, my name is John"

Arrow Function & this Issue


    const person = {
        name: "John",
        greet: () => {
            return `Hello, I'm ${this.name}`;
        }
    };
    
    console.log(person.greet()); // "Hello, I'm undefined"

11. JSON Methods

JSON.stringify()

Converts an object to a JSON string.


    const jsonString = JSON.stringify(person);
    console.log(jsonString); // '{"name":"John","age":30}'

JSON.parse()

Converts a JSON string to an object.


    const obj = JSON.parse(jsonString);
    console.log(obj); // { name: "John", age: 30 }

12. Advanced: Proxies

Intercept and customize object operations.


    const handler = {
        get(target, prop) {
            return prop in target ? target[prop] : "Property not found";
        }
    };

    const proxy = new Proxy(person, handler);
    console.log(proxy.name); // "John"
    console.log(proxy.job); // "Property not found"
